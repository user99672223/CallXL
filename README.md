# CallXL

Private, peer-to-peer, end-to-end-encrypted voice chat with chat and file transfer,
for Windows, Debian/Ubuntu Linux and iOS (sideloaded). libwebrtc data plane, Rust control
plane, Slint desktop UI, SwiftUI iOS UI.

`CLAUDE.md` is the specification. `DECISIONS.md` is the append-only decision log.
`HANDOFF.md` (written at the end of v0.1.0) explains how to install, test and operate it.
